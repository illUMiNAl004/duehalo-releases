# DueHalo

Reminders that stay on your Mac's screen until they're done.

DueHalo is in **private beta**. Want in? Join the waitlist: https://duehalo.netlify.app/waitlist.html

This repository only hosts DueHalo builds. The source code is not public.

## Install (beta testers)

1. Download the latest `DueHalo-x.y.z.dmg` from [Releases](../../releases/latest).
2. Open the DMG and drag **DueHalo** into **Applications**.
3. The first time you open it, macOS may say it can't check the app for malicious software. That's because this beta build isn't notarized by Apple yet. Open **System Settings › Privacy & Security**, scroll down, click **Open Anyway** next to DueHalo, then confirm.
4. Allow access to Reminders when DueHalo asks. It only works with the reminders already on your Mac.

## Updates

DueHalo checks this page for new versions on its own (you can turn that off in Settings), or use **Check for Updates** in the app.
